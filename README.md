# Carry-Less OS

Build a premium, modern, highly interactive landing page for a private AI systems offer called:

The Carry-Less Operating System
Private AI Systems by Alejandro Arango

Core positioning:
This is not a course, not SaaS, not therapy, not productivity coaching. It is a private AI operating system buildout for founders, creators, neurodivergent professionals, and overloaded people whose lives have been running on memory, anxiety, guilt, adrenaline, and open loops.

The page should feel like:
A dark cinematic operating room where scattered life fragments become architecture.

Visual direction:
Create a premium dark cinematic website with strong modern interaction design. It should feel like a mix of Apple product storytelling, high-end design studio, sci-fi operating system, and luxury private consulting. Dark background, glassmorphism, subtle depth, 3D layers, ambient light, slow parallax, cinematic shadows, premium typography.

Color palette:

Background: #070707 / #0A0A0A

Text: #F5F0EB

Muted text: rgba(245,240,235,.68)

Jade accent: #50DCA0

Gold accent: #C4A35A

Deep charcoal panels: rgba(255,255,255,.05)

Typography:
Use a refined serif display font for large headlines and a clean modern sans-serif for body copy. Headlines should feel editorial, cinematic, premium, and slightly philosophical. Body copy must be clear, direct, and conversion-focused.

Main interaction concept:
The hero section should include a scroll-controlled video background, not an autoplay background. The video should be treated as part of the structural design.

Behavior:

Video is paused by default.

Scrolling down moves the video timeline forward.

Scrolling up moves the video timeline backward.

The video should feel like the system is assembling as the user scrolls.

Add layered parallax elements above the video: floating cards, light beams, architecture lines, memory fragments, AI nodes.

The copy must always remain readable.

Respect prefers-reduced-motion and provide static fallback.

Interaction details for scroll-controlled video:
Use logic like this:

Get the hero section scroll progress from 0 to 1.

Wait for video metadata to load.

Set video.currentTime = scrollProgress * video.duration.
